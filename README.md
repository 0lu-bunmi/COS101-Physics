# COS 101 Physics Formulas

This project contains five basic physics formulas implemented in Python.

## Formulas included

1. **Speed:** speed = distance / time
2. **Acceleration:** acceleration = (final velocity - initial velocity) / time
3. **Force:** force = mass × acceleration
4. **Work done:** work = force × distance
5. **Kinetic energy:** KE = ½ × mass × velocity²

## How to run

Open `physics.py` in PyCharm and run the file. The program prints a sample calculation for each formula.

## Requirements

- Python 3
